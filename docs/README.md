# SSB UG website: shareable preview

Static preview of `ssb-ug-site/`, served by GitHub Pages (Settings → Pages → branch `claude/awesome-keller-wqi9w0`, folder `/docs`).
Rebuild it with `cd ssb-ug-site && bash scripts/build-preview.sh`, then copy the files listed in `out-preview/files.txt` (plus `index.html`) here.
Sign-up forms are switched off in this copy.
